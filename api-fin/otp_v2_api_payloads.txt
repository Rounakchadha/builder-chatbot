================================================================================
OTP API
================================================================================

Base URLs:
UAT  : https://backend.uatfinfinity.in/api/v1
Prod : https://bev3.finfinity.co.in/api/v1

Endpoints:
POST /leadflow/generateotpv2
POST /leadflow/validateotpv2

Auth    : None (public endpoints)
Headers : Content-Type: application/json

Use this API to send and verify OTP for customer signup/login.
On successful validation with creation_type, a new customer is created and
a JWT token pair is returned.


================================================================================
FLOW
================================================================================

Step 1: Call /generateotpv2 with mobile number or email
        -> OTP is sent to the given recipient

Step 2: Call /validateotpv2 with recipient + otp + creation_type
        -> If OTP is valid and customer does not exist, a new customer is created
        -> Returns customer_id and access/refresh token pair


================================================================================
1. GENERATE OTP v2
================================================================================

------------------------------------------------------------------------------
REQUEST PAYLOAD - Mobile
------------------------------------------------------------------------------
{
    "recipient": "9876543210"
}

------------------------------------------------------------------------------

------------------------------------------------------------------------------
| Field         | Type    | Required | Description                              |
|---------------|---------|----------|------------------------------------------|
| recipient     | string  | Yes      | Mobile number OR email address           |
| otp_length    | integer | No       | OTP length (4 or 6). Defaults to 6       |
| campaign_code | string  | No       | Journey/campaign identifier              |

================================================================================
3. INTEGRATION EXAMPLES
================================================================================

------------------------------------------------------------------------------
Signup / Login with Mobile
------------------------------------------------------------------------------
1. POST /leadflow/generateotpv2
   {
       "recipient": "9876543210"
   }

2. User receives OTP

3. POST /leadflow/validateotpv2
   {
       "recipient": "9876543210",
       "otp": "123456",
       "creation_type": "MOBILE"
   }

4. Response contains customer_id + access/refresh tokens

------------------------------------------------------------------------------

   }

2. User receives OTP

3. POST /leadflow/validateotpv2
   {
       "recipient": "user@example.com",
       "otp": "123456",
       "creation_type": "EMAIL"
   }

4. Response contains customer_id + access/refresh tokens


================================================================================
4. NOTES
================================================================================

1. Response envelope is always:
   {
       "data": [...],
       "error_msg": "...",
       "error_code": "...",
       "error_dtl": [] or "...",
       "activity": null
   }

2. Use error_code == "" to determine success.

3. On validate success:
   - If customer already exists, backend returns existing customer data + tokens
   - If customer does not exist and creation_type is provided, new customer is
     created and tokens are returned

4. Lockout rules:
   - max attempts = 3
   - lockout duration = 30 minutes
   - OTP validity = 10 minutes
   - max resend attempts = 3
   - resend cooldown = 60 seconds
